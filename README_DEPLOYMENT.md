# ERP Production Deployment Guide

This guide covers the deployment of the ERP system on a Linux (Ubuntu) production environment using Nginx, PM2, and MariaDB.

## 1. Prerequisites Installation

Install Node.js, NPM, Nginx, and MariaDB:
```bash
# Update packages
sudo apt update && sudo apt upgrade -y

# Install Node.js (v18+)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Install Nginx and MariaDB
sudo apt install -y nginx mariadb-server

# Install PM2 globally
sudo npm install -g pm2
```

## 2. MariaDB Setup

Secure your database and create the ERP database:
```bash
sudo mysql_secure_installation

# Log into MySQL
sudo mysql -u root -p

# Create database and user
CREATE DATABASE erp_db_new CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'erp_user'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON erp_db_new.* TO 'erp_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

## 3. Clone Repository

```bash
cd /var/www
sudo git clone <your-repo-url> erp
sudo chown -R $USER:$USER /var/www/erp
cd /var/www/erp
```

## 4. Environment Configuration

### Backend
Create `/var/www/erp/backend/.env`:
```env
DB_HOST=localhost
DB_USER=erp_user
DB_PASS=your_strong_password
DB_NAME=erp_db_new
DB_PORT=3306

JWT_SECRET=your_production_secure_random_string

NODE_ENV=production
PORT=5002

CORS_ORIGIN=https://erp.lancerstech.com
```

### Frontend
Create `/var/www/erp/frontend/.env.production`:
```env
VITE_API_URL=/api
VITE_SOCKET_URL=/
```

## 5. Deployment using deploy.sh

We have provided a script to automate the build, initialization, and PM2 restart.
Run:
```bash
chmod +x deploy.sh
./deploy.sh
```

*(Note: The first time you run this, it will run `npm run db:init` which creates tables, syncs schemas, and generates the default admin user `admin@erp.com / admin123`)*

## 6. Nginx Configuration

Create a new Nginx block:
```bash
sudo nano /etc/nginx/sites-available/erp
```

Paste the following configuration:
```nginx
server {
    listen 80;
    server_name erp.lancerstech.com;

    # Frontend Static Files
    root /var/www/erp/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Backend API Proxy
    location /api/ {
        proxy_pass http://localhost:5002/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Socket.IO Proxy
    location /socket.io/ {
        proxy_pass http://localhost:5002/socket.io/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

Enable the site and restart Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/erp /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 7. SSL Certificate Setup (Certbot)

Install Certbot and enable HTTPS:
```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d erp.lancerstech.com
```

## 8. PM2 Startup Script

Ensure PM2 restarts on server reboot:
```bash
pm2 startup
# Run the command generated by the above command
pm2 save
```

Your ERP is now fully productionized!
